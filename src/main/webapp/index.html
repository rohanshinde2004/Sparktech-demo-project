This page was built and packaged by Maven.

You are looking at a WAR file running on Tomcat. Its source lives in GitHub, and Maven compiled, tested and packaged it on your EC2 server.

mvn clean package

The Maven default lifecycle

  1. validateChecks that pom.xml and the project structure are correct.
  2. compileCompiles src/main/java into target/classes.
  3. testRuns the JUnit tests with Surefire. A failing test stops the build.
  4. packageCreates target/sparktech-demo.war.
  5. verifyRuns integration tests and quality checks.
  6. installCopies the WAR into ~/.m2/repository.
  7. deployUploads the WAR to a remote repository such as Nexus.
